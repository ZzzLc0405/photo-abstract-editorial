# 照片衍生抽象画提示词（中文）

严格将上传照片作为唯一的视觉信息来源，只生成一张独立的抽象作品，并且只生成一个方案。照片仅供内部分析，不得在最终画布中出现、被复制，或保留为可辨识的摄影区域。不得添加标题、副标题、说明、标签或任何其他文字。

## 工作方法

在内部执行以下流程，不输出分析文字：

**解构 → 选择性保留 → 抽象 / 提炼 → 重构**

1. 找出三至六个决定性事实：主体质量、相对尺度、位置、轴线、方向、间隔、重复、遮挡、深度、明暗层级、色彩角色与留白。
2. 删除表面纹理、透视细节、背景杂讯和低信息装饰。
3. 用尽可能少的标记重构保留的关系。
4. 让成品第一眼是克制的抽象构成，第二眼才使人联想到这张特定照片。

这不是风格迁移、矢量化、描摹、色调分离、照片滤镜或场景插画。

## 抽象规则

- 普通场景、自然景观、地平线、水面和人群：保留方向、密度、间隔、层级、运动与色彩关系，舍弃完整物体轮廓。
- 标志性建筑或独特主体：最多保留一至三个身份线索，如外部体量、负空间、檐线、收分、拱洞、尖顶或层叠节奏；省略表面细节。
- 有机群体：用相互重叠的柔和有机色块表达密度和运动；不画内部图案与写实高光。
- 人物：每个人只用一个连续、不规则的短竖标记或轻微收分的色块；不单独画头部、四肢、面孔或衣服。
- 道路、栏杆、地平线和岸线：压缩为一至两条细轴线和少量不规则中断。
- 小型代表物件：只保留两至三个平面标记，靠比例与位置建立辨识，不表现写实材质或体积。

保留最低必要辨识度，而不是复制物体。

## 标记与色彩系统

使用一个主要标记家族，最多两个辅助家族。可使用平面或微有机色块、柔和不规则团块、弧形或收分笔触、短条、层叠色带、细结构线和简化建筑体量。

每个标记都必须对应照片中的视觉事实。避免无来源装饰、虚构对称、规则化间距、通用图标和信息图几何。让尺度、位置与间距保留轻微变化，形成观察所得的自然节奏。

所有颜色只从照片中提取，并减少数量、降低饱和度。使用一个主色角色、一个深色结构角色、一个浅色或中性色角色，以及最多一至两个确实存在于原图中的小面积强调色。

## 画布与版式

生成一张独立的抽象画布，不设置照片区域、上下分割、双联画、面板拼接、画框、边框、拼贴、胶带、卡片、阴影或样机效果。

背景必须完全平坦、均匀、连续，使用中性象牙色，优先 **#F3F0E8** 或与其接近且协调的象牙色。将抽象母题放在中央、中下部，或由原图关系支持的非对称位置。通常保留约 55–75% 的干净留白。横向主体可以更宽，纵向主体可以更高，但不得填满画布，也不要把母题缩成通用小图标。

除非用户指定尺寸，画布方向可跟随原照片的构图方向。

## CLEAN 模式与输出

不得使用渐变、光照变化、发光、阴影、暗角、色带、接缝、纸张纹理、颗粒、噪点、纤维、水彩底纹、雾、污渍、褪色、扫描痕迹、贴图或压缩伪影。抽象标记可以具有轻微自然边缘和手工不规则感。

只调用一次图像生成，并且只请求一个结果。最终只输出、附加和展示一张完成的无文字抽象作品。不得提供多个候选方案、多个变体、重复图片或前后对比图，也不得在同一画布中放置两个相同副本。如果工具意外返回重复结果，只保留并返回第一张唯一图片。不得包含原照片、摄影碎片、标题、副标题、说明、字母、数字、日期、编号、图例、签名、logo 或水印。

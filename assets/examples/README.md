# Finished output examples

These images are complete photo-and-abstract editorial outputs, not source photographs or reusable templates. Use them only to understand the skill's intended behavior. Do not copy their subjects, palettes, motifs, titles, or layouts into new work.

| File | Behavior demonstrated |
| --- | --- |
| `case-1.jpg` | Compresses a wide sunset into sparse horizontal bands, structural axes, and a restrained title/subtitle treatment. |
| `case-2.jpg` | Reduces landmark architecture and a foreground crowd to a few identity cues, varied masses, and irregular human marks. |
| `case-3.jpg` | Translates an organic balloon cluster, human rhythm, railing axis, and background architecture into a compact layered motif. |
| `case-5.png` | Preserves a distinctive building through minimal planar masses while retaining the waterline and distant-land relationships. |
| `case-6.jpg` | Uses a small set of architectural curves and vertical spacing to express a dialogue between two source-photo subjects. |

Across the gallery, the original photograph remains the sole content source. The examples demonstrate relationships and constraints rather than fixed styling: each new output must derive its spatial facts, colors, abstraction, and title independently from the user's photograph.
